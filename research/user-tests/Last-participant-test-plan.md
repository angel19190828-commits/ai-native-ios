# AI 原生 iOS 概念｜简易用户测试计划

你好！感谢你帮我测试这个概念。整个过程大约需要 **15–20 分钟**。这不是在测试你的能力，而是在测试当前流程和设计是否容易理解。

## 测试前准备

- 使用你平时使用的手机
- 开启屏幕录制
- 测试时请尽量说出你正在想什么，例如：“我现在在找时间”“我不确定下一步去哪”
- 请勿展示真实的私人邮件、联系人或敏感信息；测试使用我提供的模拟邀请

## 背景问题（2–3 分钟）

1. 你平时会使用 Siri、Calendar、Reminders 或 Shortcuts 吗？分别用来做什么？
2. 收到活动、预约或面试邮件后，你通常怎么处理？
3. 你会手动把邮件中的信息加入日历或提醒事项吗？为什么？
