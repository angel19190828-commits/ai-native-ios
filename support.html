Taskspace AI 内测支持

这里记录当前 iOS TestFlight 与 Android 内部测试版本的使用方式、权限说明和问题反馈路径。

当前状态

应用仍处于内部测试准备阶段。安装链接会在真实 EAS 构建、设备验收和签名配置完成后提供；网页原型不是可提交商店的移动应用。

基本测试流程

  1. 使用受邀邮箱完成一次性验证码登录。
  2. 粘贴面试或预约邀请，并按需填写出发地。
  3. 审阅 AI 提取的时间、地点、通勤和提醒。
  4. 点击发送确认；授予需要的 Calendar 与通知权限。
  5. 观察 Calendar → 通勤 → Reminders 的执行回执。执行中可使用橙色停止按钮停止尚未开始的步骤。

权限与常见问题

  • Calendar：用于检查冲突并创建你已确认的日程。
  • 通知：用于创建你已确认的准备和出发提醒。
  • 网络：用于登录、同步任务、AI 规划和通勤估算。

如果某一步失败，任务会保留已经完成的回执，并允许重试尚未完成的步骤。撤销权限请前往系统设置；删除应用本身不会删除已经写入 Calendar 的事件。

删除数据

在邀请输入页或任务详情底部选择“永久删除账户与数据”，确认后会删除认证账号及关联的云端任务数据，并清理设备上的加密缓存和会话。单个任务也可以独立删除。

反馈问题

请在 GitHub Issues 提交问题，并提供平台、系统版本、应用版本和可复现步骤。不要附上真实邀请正文、验证码、访问令牌或其他敏感信息。
